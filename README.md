# 知到 / 智慧树刷课助手（顺序播放外观 + GitHub 逻辑）

Tampermonkey 油猴脚本，用于知到/智慧树课程视频的顺序播放与任务点完成。

- 当前版本：**1.2.0**
- 脚本文件：[`zhidao刷客-GitHub融合版.user.js`](./zhidao刷客-GitHub融合版.user.js)
- 纯浏览器端脚本：没有服务端、不上传数据、默认不联网。

## 功能

- 自动播放 / 静音 / 1x 原速（面板里可调到 1.25x、1.5x）
- 目录进度识别（legacy / wisdom / hike 等常见页面结构）
- 断点续播、自动跳过已学完节点、播完自动下一节
- 视频弹题处理：
  - 优先读页面内嵌答案 / 本地规则推测
  - 多通道点击 + 多轮重试；平台忽略合成点击时隐藏遮挡层并恢复播放，尽量避免视频停住、时长不涨
  - 支持 `#tmDialog_iframe` 里的弹题
- 停止状态记忆：面板点「停止」后，下次进页面不自动开跑
- 右下角「顺序播放」面板：启动/停止、状态行、进度条、最近日志、设置

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开脚本文件的 raw 地址安装，或新建脚本后粘贴文件内容
3. 进入知到/智慧树课程学习页，右下角出现「顺序播放」面板即生效

> 如果仓库是 Private，raw 地址需要登录 GitHub；也可以直接下载文件后拖进 Tampermonkey。

## 默认策略

- 不接 AI / 题库 / LLM，不联网（弹题只用本地规则推测）
- 不自动选课、不跨课、不碰作业/考试
- 弹题答错不影响视频完成（平台提示这类巩固题不计成绩）
- 如果在设置里关闭「视频弹题：自动选一个」，遇到弹题会停下来等待手动作答
